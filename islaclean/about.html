About this project

A fictional business, built for real practice.

IslaClean Palawan is not a client and not an operating cleaning company. Eric John N. Cruz created it as an independent environment for practicing SEO implementation and documenting how the work is approached.

What is real here

  • The HTML, CSS, and JavaScript implementation.
  • The page architecture and internal-link structure.
  • Unique titles, meta descriptions, and page-specific H1s.
  • Intentional noindex handling for a fictional brand.
  • Demo dataLayer events for CTA and form interactions.
Practice scope

Research → build → optimize → verify → report

The purpose is to have a controlled website where changes can be implemented and discussed honestly in an interview.

Structure

Separate service intents, local page, blog hub, and contact path.

On-page

Unique metadata, headings, contextual internal links, and readable copy.

Measurement

Demo CTA and form interactions pushed to dataLayer for later GA4/GTM practice.
