# IslaClean Palawan — SEO Practice Site

Independent practice project by Eric John N. Cruz. This is a fictional local cleaning brand and has no client affiliation.

## What this project demonstrates

- Multi-page static site built with HTML, CSS, and JavaScript
- Separate service pages for distinct search intent
- Puerto Princesa local-service architecture
- Unique page titles, meta descriptions, and H1s
- Contextual internal linking
- Responsive layout
- Intentional `noindex, nofollow` because the business is fictional
- Demo `dataLayer` events for CTA clicks and form submission
- Non-functional lead form that does not transmit or store personal data

## Pages

Home, Services, House Cleaning, Deep Cleaning, Move-In / Move-Out Cleaning, Service Area, About, Blog, Deep Cleaning Checklist, Contact.
