AI-assisted work

Use the assistance.
Own the judgment.

I use ChatGPT, Claude and Gemini to support research, content planning, drafting and summarization. The useful output is a reviewed piece of work, not an unchecked response.

  1. Start with the source

    Use the brief, business scope and source material to define the task.

  2. Review and refine

    Check factual claims, intent, dates and recommendations against the source. Edit for clarity and remove unsupported conclusions.

  3. Validate the output

    Check links, content and implementation before handoff or publication. My independent website project shows this approach in a browsable deliverable.
